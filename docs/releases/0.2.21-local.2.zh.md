# 0.2.21-local.2 — 本地兼容性与可靠性优化

基于 shuind/dsh-codex-harness 0.2.21（上游提交 079794c9c093b13aac30de3358a5312d4642a6ee）的独立优化版本，保留上游 MIT 许可证及包名。

## 改动

- 完善远程压缩取消检查，覆盖请求完成、解码及逐块输出期间的取消竞争；取消后不再继续发布摘要或误触发本地回退。
- 补充压缩失败、部分摘要中断、历史保留及后续自动重试的回归测试。
- 将本插件诊断文件限制为最新 32 个；限制诊断帧和旁路读取大小，避免诊断处理占用过多资源。
- 适配 DSH NEXT 0.2.1-rc.2 的 preset registry，同时保留旧版文件式预设兼容。
- 在新版 registry 注册路径中将旧 workflow-worker-thread 映射为 workflow-ptc。
- 对新版内置预设显示只读状态，避免尝试直接修改安装包中的预设。

## 验证

152 项测试通过；严格 TypeScript 检查、服务端与客户端构建通过；本机 desktop Profile 安装与配置合成通过。尚未验证重启后的真实模型调用。

## 安装

下载本发布附带的 `shuind-dsh-codex-harness-0.2.21-local.2.tgz`，通过 DSH 插件管理器安装。重启 DSH，在新会话选择 Codex 预设。

本版本为独立维护的预发布版本，不代表上游正式发布，也未发布到 npm。
